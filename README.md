Entry for the [make.fun bounty "Funniest Time Machine Warning Label"](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) — the funniest one-line warning label for a time machine, at most 120 characters.

## Run

```sh
python3 main.py
```

Writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints it to stdout. No network, no dependencies, deterministic.
